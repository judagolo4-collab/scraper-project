Crea un nuevo proyecto de scraping web en Python. El objetivo es construir una arquitectura de clases modular y reutilizable para manejar diferentes tipos de sitios web (estáticos, dinámicos).

**Estructura del Proyecto y Clases Requeridas:**

1.  **Clase Base (Abstracta): `BaseScraper`**
    * **Propósito:** Manejar la configuración global, inicializar el logging, y estandarizar el formato de los resultados (`List[Dict[str, Any]]`).
    * **Métodos Clave:**
        * `__init__(config)`: Inicializa la configuración y el logger.
        * `_setup_logging()`: Configura el sistema de logging.
        * `add_result(data)`: Almacena un ítem extraído.
        * `scrape()`: **Método abstracto** que debe ser implementado por las clases hijas.

2.  **Clase Concreta para Contenido Dinámico: `SeleniumScraper`**
    * **Herencia:** Hereda de `BaseScraper`.
    * **Propósito:** Gestionar operaciones con WebDriver (Chrome/Firefox) para sitios dinámicos. Debe operar en **modo headless** (sin abrir ventanas visibles) por defecto.
    * **Métodos Clave:**
        * `setup_driver()`: Configura el WebDriver con opciones *headless*.
        * `teardown_driver()`: Cierra la sesión del WebDriver.
        * `wait_for_selector()`: Espera la presencia de un elemento.
        * `next_page()`: Implementa lógica de paginación (por botón o URL).
        * `extract_link_and_type(element, selector_or_xpath, use_xpath)`: **Método fundamental**. Extrae una URL de un elemento (usando CSS o XPath) y la clasifica como `'pdf'`, `'web'` o `'unknown'` basándose en la extensión o el texto del enlace (ej: "Ver Documento").

3.  **Clase Específica (Ejemplo de Implementación): `SenadoColombia`**
    * **Herencia:** Hereda de `SeleniumScraper`.
    * **Propósito:** Implementar la lógica de extracción para un sitio concreto (simular la extracción de proyectos de ley).
    * **Métodos Clave:**
        * `scrape()`: Sobrescribe el método principal para iterar por la lista principal, usar el método de paginación, y llamar a `_process_item`.
        * `_process_item(element)`: Extrae los datos básicos de la tabla y luego realiza una **navegación multiventana** (abre el enlace de detalle en una nueva pestaña, extrae un resumen y usa `extract_link_and_type` con XPath para encontrar el enlace "Ver Documento", cierra la pestaña y vuelve).

**Requisito de Retorno:** Proporcionar los tres archivos de clase (`base.py`, `selenium_scraper.py`, `senado_colombia.py`) con la implementación completa de esta arquitectura.
